Twitch chat voting. Type your Twitch channel name in the text field and press Enter; you hear when the chat is connected. The interval and maximum votes lists set how often a vote runs and how many options it offers, and the check boxes turn single vote options on or off. Each new vote is announced with the numbers viewers type in chat, for example #2. {Status} shows the running vote counts and the time left, Enter on that line opens or closes these settings. The result banner says what the viewers chose. Escape closes the settings and returns to the map. Captions, reading chat aloud and the overlay status file are in the mod settings, group Streaming. = Twitch 聊天投票。在文字方塊中輸入你的 Twitch 頻道名並按 Enter，聊天連線成功時會有提示。「間隔」和「最多投票項」清單設定投票的頻率和選項數量，核取方塊可單獨開關各個投票選項。每次新投票都會播報觀眾需要在聊天中輸入的編號，例如 #2。{Status} 讀出目前票數和剩餘時間，在該行按 Enter 可開啟或關閉這些設定。結果橫幅會說明觀眾的選擇。Esc 關閉設定並返回地圖。字幕、朗讀聊天和直播疊加狀態檔案在模組設定的「直播」分組中。
